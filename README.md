# flex_brickphone

[PREVIEW](https://streamable.com/23yhpm)

A **VIBE CODED** brickphone system for FiveM.
</br>
Will not fix any bugs thats why its vibecoded and free.
</br>
</br>

# FEATURES
- Group creation - ADD / REMOVE / RENAME
- Group chat
- Stored sql messages for groups
- Contact creation / Deletion with exports
- Message detection with exports
- Default crafting contact - Order items to craft if player has the items needed
- Show contact only on amount of police on duty
- Job contacts

</br>
</br>

# SETUP

Look inside the docs folder to start the setup and don't forget to upload the sql.
</br>
Don't forget to add the ox_inventory brickphone item.
